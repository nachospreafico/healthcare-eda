# Healthcare EDA

End-to-end exploratory data analysis of synthetic healthcare encounter
data using Python.

This project demonstrates a structured EDA workflow, including data
quality assessment, cleaning, feature engineering, statistical analysis,
visualization, and business insight generation.

## Objectives

-   Assess dataset quality and identify data issues
-   Clean and validate raw healthcare data
-   Explore patient, encounter, operational, and financial metrics
-   Derive actionable insights through exploratory analysis
-   Communicate findings using clear visualizations and summaries

## Dataset

The analysis uses a synthetic dataset of **75,000 hospital encounters**
spanning **2024--2025**.

Each record represents a single patient encounter and includes
information such as:

-   Patient demographics
-   Admission and discharge dates
-   Diagnosis category
-   Facility type
-   Insurance type
-   Length of stay
-   Treatment cost
-   30-day readmission
-   Patient satisfaction

The dataset intentionally contains realistic data quality issues
(missing values, duplicates, inconsistent formatting, invalid values,
and outliers) to simulate a real-world analytical workflow.
